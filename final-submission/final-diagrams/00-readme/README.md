# RoomEase Final Diagrams (Mermaid)

These Mermaid files are prepared for FYP report sections:
- System Design
- Artefact Design

## Diagram Set

1. Functional Decomposition Diagram (FDD)
2. System Architecture Diagram
3. Overall Use Case Diagram
4. Database ER Diagram
5. Core Class Diagram
6. Activity Diagrams
7. Sequence Diagrams
8. Deployment Diagram
9. Data Flow Diagrams (Context + Level 1)

## Draw.io Import

1. Open draw.io
2. Insert -> Advanced -> Mermaid
3. Paste file content
4. Edit styling/positions as needed

## Style Choice

Flowcharts use Mermaid init config with linear edges to keep connectors straight.
